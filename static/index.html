How does it decide what's vandalism?
  1. Scan. The tracker reads Wikipedia's RecentChanges feed (the same one as this page: no bots, no category changes, no Wikidata) and looks at every human edit to an article.
  2. Check 1 — bad faith. Wikipedia's own ORES "good faith" model scores each edit. Edits it thinks are at least 50% likely to be made in bad faith become candidates.
  3. Check 2 — is it really vandalism? Every candidate is examined, then re-checked at 1, 3, 6 … 120 minutes after the edit. It looks at the text that was added (swearing, insults, gibberish, blanking…), Wikipedia's edit-filter tags, an independent machine-learning model (Wikimedia's revert-risk model), and how Wikipedians reacted: was it reverted as vandalism, was the vandal blocked, did admins hide or delete it?
  4. Shown here. Only edits that check 2 confirms as vandalism and that Wikipedia has already cleaned up. Everything else keeps being re-checked in the background and appears as soon as it is confirmed and cleaned up.
  5. Links. Each one links to the vandalized version (a permanent link to the page exactly as the vandal left it), plus the diff.
  6. Page history. Give it a page and it reads that page's latest edits, picks out the ones Wikipedia reverted (or admins hid), and runs those through the same two checks.
